# Guia de fluxo, design e melhorias

[Baixar o pacote ZIP](https://github.com/mzinhoww-svg/memo-brasil/raw/refs/heads/main/docs/design/downloads/memoriesmt-melhorias-fluxo-design.zip)

Entre no GitHub com uma conta que tenha acesso a este repositório privado. Se o navegador abrir a página do arquivo, use **Download raw file** (ícone de download).

Depois de baixar, extraia o ZIP e abra `guia-interativo.html` no navegador. O guia funciona sem instalar nada e sem serviços externos. O pacote também inclui a explicação em Markdown, a rastreabilidade dos 25 achados e o relatório com capturas da versão publicada.

Para ler sem baixar: [melhorias de fluxo e design](../UX-FLOW-IMPROVEMENTS.md) e [validação das correções](../UX-VALIDATION.md).

O guia distingue as correções implementadas das propostas futuras de produto e design.
