# Logos

- `memoriesmt-wordmark.svg`: wordmark principal, "memories" + selo MT. Uma tinta: `#1C1917` (tinta). Sobre `fundo`, `neutro` e fotos claras.
- `memoriesmt-wordmark-negativo.svg`: wordmark em `#FFFFFF`. Sobre tinta, tema Noite e fotos escuras.
- `memoriesmt-selo.svg`: selo MT, disco com letras vazadas. Uma tinta: `#1C1917`. Ícone, favicon, avatar e assinatura.
- `memoriesmt-selo-negativo.svg`: selo em `#FFFFFF`, letras vazadas mostram o fundo.
- `memoriesmt-icone-app.svg`: ícone do app, 140px com cantos `radius-icone`. Duas tintas: fundo `#1C1917`, selo `#FFFFFF`.
- `memoriesmt-icone-app-ao-vivo.svg`: ícone do app com o ponto `rec` (`#E1261C`) no canto. Só enquanto há evento ao vivo.

Os desenhos são contornos vetoriais, sem dependência de fonte. Mínimos: selo 16px, wordmark 96px de largura. Proteção: 25% do diâmetro do selo.
