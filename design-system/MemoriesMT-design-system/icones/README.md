# Icones

Ícones de traço em grade de 24px: traço 2px, terminações e cantos arredondados, sem preenchimento. Uma tinta: `#1C1917` (tinta). Para recolorir, use o SVG inline com `stroke="currentColor"`. Na navegação, 22px; o item atual usa traço 2,2px.

- `camera.svg`: postar, tirar foto. Sempre dentro do CTA "Postar daqui".
- `agora.svg`: aba Agora, o feed ao vivo.
- `explorar.svg`: aba Explorar.
- `voce.svg`: aba Você.
- `casal.svg`: aba Nosso casamento, no painel dos noivos.
- `favoritos.svg`: favoritos dos noivos.
- `moderar.svg`: moderação.
- `baixar.svg`: downloads.
- `fechar.svg`: fechar tela ou folha.
- `sem-sinal.svg`: estado sem conexão.
- `mais.svg`: mais opções. Exceção: três pontos cheios em `#1C1917`.
