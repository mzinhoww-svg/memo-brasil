# VisionTile

Miniatura de uma visão no Explorar: a foto de capa com o nome da visão no rodapé.

Grade de duas colunas (`mm-visions`), altura 140px, `radius-control`. Rótulo 13px peso 600 em `evento-profundo` sobre `evento-superficie`. Cada tile é um link para a visão. O consumidor fornece nome, foto de capa e destino.
