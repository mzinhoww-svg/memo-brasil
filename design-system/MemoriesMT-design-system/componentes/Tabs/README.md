# Tabs

Abas de 44px para alternar filas e filtros no admin.

Fundo `neutro`; a aba ativa com `aria-selected="true"` vira `acao`. Rótulo com contagem: "Pedidos de remoção · 3". Use `role="tablist"` no grupo e `role="tab"` em cada `<button>`. Linha `divisor` abaixo do grupo. O consumidor fornece rótulos, contagens e o painel controlado.
