# StatTile

Card de número para o painel dos noivos e o admin.

Card em `fundo` sobre página `neutro`, `radius-panel`, número em `numero` (30px, 800) e rótulo 13px em `apoio`. Grade de duas colunas. Números no padrão brasileiro ("1.284", "18 de 20"). Telas com dados fictícios trazem "dados de exemplo" no eyebrow.
