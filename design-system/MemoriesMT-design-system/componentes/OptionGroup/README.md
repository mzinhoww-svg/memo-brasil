# OptionGroup

Grupo de opções exclusivas em botões de 48px, para configurações do admin.

Use `mm-group` com um rótulo `mm-group-label` e a grade `mm-opts` (duas colunas) ou `mm-opts--lista` (uma coluna, texto à esquerda). Cada `mm-opt` é um `<button>` com `aria-pressed`; o selecionado vira `acao`. O consumidor fornece rótulos curtos e o estado. Para mais de seis opções, use um campo de seleção.
