# LiveIndicator

Ponto `rec` com rótulo em `eyebrow`, para sinalizar que o evento está ao vivo ou que algo acabou de acontecer.

Use "Ao vivo" no topo do feed, a hora atual no painel dos noivos ("21h40") e "Subindo 2 de 3" durante o envio. O ponto nunca aparece sozinho: sempre com a palavra. Um indicador por tela.
