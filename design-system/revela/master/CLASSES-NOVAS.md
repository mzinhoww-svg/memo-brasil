# Classes novas (todas em `html/assets/revela2-screens.css`, bloco "Master: console completo")

Nenhum token novo. Só as cores, raios e fontes que já existiam.

| Classe | Para quê |
|---|---|
| `.mdim` | Esmaece a tela-base atrás de uma folha de ação |
| `.mstate` | Estado vazio, erro e "Sem permissão" (ícone, título, texto, ação) |
| `.msk` | Barra de esqueleto do estado "carregando" |
| `.st--mute` | Selo neutro (E-mail, Convidado, revogado, cancelado) |
| `.mpager` | Paginação fixa no rodapé da área principal |
| `.chip--sm` | Chip pequeno para os motivos agregados |
| `.kv` | Lista de rótulo e valor (detalhes e folhas) |
| `.mgrid3` | Grade de 3 colunas do detalhe do evento |
| `.mminis`, `.mmini`, `.mmini--warn` | Quatro gráficos pequenos de barras lado a lado |
| `.cbx--sm` | Caixa de seleção de linha (lote de eventos de teste) |
| `.runs` | Pontos das últimas execuções de um job (verde ok, vermelho falha) |
| `.nums` | Números das fotos escolhidas em um pedido de impressão |
| `.tl--todo` | Passo ainda não alcançado na linha do tempo de status |

Reaproveitadas sem mudança: `.mside`, `.mnav`, `.mtop`, `.msearch`, `.envb`, `.mhead`, `.mtiles`, `.tile`, `.mtable`, `.mtr`, `.mth`, `.seg`, `.chip`, `.mcard`, `.gauge`, `.hbar`, `.bars`, `.rv-group`, `.rv-row`, `.mnote`, `.st`, `.mmodal`, `.mmodal-card`, `.otp`, `.diff`, `.mfield`, `.mpublish`, `.tls`, `.tl`, `.errline`, `.countdown`, `.rv-field.area`, `.rv-toggle`.

Dois ajustes em classes existentes: `.mfield svg` ganhou tamanho fixo de 16 px e `.mmodal-card .rv-btn` não quebra linha.
